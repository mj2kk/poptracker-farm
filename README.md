# PopTracker Farm

PopTracker Farm выдаёт задания Android-устройствам, отслеживает их состояние и принимает результаты. В репозитории также сохранена публичная часть эксперимента E078 по проверке региона авторов.

| Каталог | Содержимое |
| --- | --- |
| [Farm](farm/) | Исходники Android-приложений, сервер на PHP, миграции базы и интеграция панели управления. |
| [APK Farm](farm/apk/) | Четыре отладочные сборки Android. |
| [Эксперимент E078](research/E078/) | Исходники для проверки сохранённых данных, контрольные параметры запуска и агрегированные результаты эксперимента. |

Сборки Farm и исследовательский APK E078 — разные приложения. Исходный APK E078 не найден. Публичная часть E078 предназначена для анализа сохранённых результатов и не включает исполняемый сборщик данных.

Для развёртывания Farm понадобятся собственные настройки сервера и ключи. Данные рабочих устройств и выгрузки базы в репозиторий не входят.
