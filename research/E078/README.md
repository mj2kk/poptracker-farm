# E078. Проверка региона авторов

14 ноября 2026 года в эксперименте обработали 3 471 кандидата за 348 пакетов. Код региона был получен для 3 304 авторов. У 2 303 из них зафиксирован ZA (Южная Африка), у 1 001 — другие коды. В 167 случаях регион остался неизвестным. Это исторические значения на дату проверки.

В каталоге опубликована часть материалов E078 для анализа сохранённых результатов. Оригинальный APK E078 отсутствует. Полный исполнитель эксперимента в эту публикацию не входит. Исторический SHA-256 оригинального APK по квитанции сборки — `9a2bb1288847588fbcd07fe9b8703ef8a583c66667d9e6b663c132ffa8e6579a`.
