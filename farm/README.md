# PopTracker Farm

PopTracker Farm управляет Android-устройствами через HTTPS. Агент принимает типизированные задания, сохраняет их состояние на телефоне и возвращает результаты серверу. Оператор видит устройства, состояние дисплея, очередь и историю в панели управления.

| Каталог | Содержимое |
|---|---|
| `android/app` | Основной Android Agent, регистрация, heartbeat и выполнение заданий. |
| `android/ipc-client`, `android/ipc-provider`, `android/ipc-contract` | Два тестовых Android-приложения и их общий IPC-контракт. Ответы тестового провайдера синтетические. |
| `android/geo-executor` | Отдельный исполнитель для проверки пакетов UID/VID. Он обращается к отдельно установленному совместимому поставщику и возвращает `source_unavailable`, когда поставщик отсутствует. |
| `apk` | Четыре debug-APK приложений Farm и файл `SHA256SUMS`. |
| `server` | PHP API, CLI, схемы и миграции MySQL, планировщик, конфигурации развёртывания и тесты. |
| `dashboard` | Контроллер, страницы React, конфигурация, тест и патч интеграции для существующего Laravel-приложения. Хост-приложение разворачивается отдельно. |
| `docs` | [Настройка и сборка](docs/setup.md), [API устройства](docs/device-api.md) и [протокол выдачи заданий](docs/step-03b1-lease-protocol.md). |

## Сборка Android

Откройте каталог `android` в Android Studio с установленным SDK 37. Из этого каталога можно собрать модули и запустить локальные тесты:

```sh
./gradlew :app:assembleDebug :geo-executor:assembleDebug :ipc-client:assembleDebug :ipc-provider:assembleDebug
./gradlew :app:testDebugUnitTest :geo-executor:testDebugUnitTest :ipc-provider:testDebugUnitTest
```

Для проверки приложенных APK выполните из каталога `apk` команду `shasum -a 256 -c SHA256SUMS`. Агент и GEO-исполнитель проверяют подписи приложений при взаимодействии. Компоненты, которые собираются самостоятельно, должны использовать согласованную подпись. Адрес сервера для приложенных APK задан в [Protocol.kt](android/app/src/main/java/cloud/poptracker/farm/Protocol.kt). Перед сборкой для собственного сервера укажите свой HTTPS-адрес.

## Состав открытой копии

Сохранены исходники Farm, шаги проектирования и четыре собранных APK. Имя SSH-подключения, локальный путь к ADB и адресация конкретного лабораторного устройства вынесены из тестового скрипта в настройки окружения. В демонстрационных командах и тестах используются примеры идентификаторов. Два контрольных UID/VID публичных аккаунтов сохранены как часть контракта проверки GEO. Для настройки сервера используются собственные учётные данные оператора.

Рабочие базы, журналы устройств и заданий, скриншоты, токены, ключи подписи и личные настройки IDE исключены. APK в этой папке принадлежат приложениям Farm. Поставщик свежих регионов и сторонние APK в состав Farm не входят.
