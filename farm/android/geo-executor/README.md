# Свежая проверка региона автора в Farm

В панели «Телефоны» откройте «Проверить страны авторов» и нажмите «Подготовить выборку». Farm выберет до десяти авторов с их роликами и добавит два контрольных аккаунта. Если агент сообщил о готовом источнике, появятся выбор телефона и кнопка «Передать выборку на телефон». В открытой панели нажмите «Обновить выборку», чтобы посмотреть результат задания.

На устройстве нужны подписанные одним сертификатом Farm Agent 0.6.0, Farm GEO и источник оригинального поля автора. Два первых приложения собираются из этого проекта. Источник в комплекте отсутствует. Обычный запуск не расходует кредиты API. Старый исследовательский APK E078 обрабатывал собственный фиксированный список. Контракт ниже описывает интерфейс для источника с разрешённым доступом к свежим данным.

## Android IPC

Агент вызывает методы ContentProvider исполнителя по адресу `content://cloud.poptracker.farm.geoexecutor`. Исполнитель разрешает вызовы только агенту с подписью Farm и собственному UID. При обращении к источнику он проверяет authority, имя пакета и сертификат. Ожидаемый пакет и authority — `cloud.poptracker.farm.regionsource`, разрешение — `cloud.poptracker.farm.regionsource.permission.OBSERVE` уровня signature.

* `ready_v1` возвращает Bundle с булевым `ready`. Источник сообщает true только при наличии доступа, позволяющего выполнить замер. Сам вызов готовности бесплатен.
* `observe_batch_v1` принимает Bundle со строкой JSON `batch`, строками `nonce` и `scope_sha256`. JSON задания содержит `version=1`, `request_id`, `scope_sha256`, массив `members`. Каждый элемент задаёт строковые UID и VID и роль target или control. Значение SHA-256 вычисляется от последовательности строк UTF-8 `role|uid|vid\n` в порядке задания.
* Источник возвращает строку JSON в Bundle под ключом `response`. Ответ содержит `version=1`, исходные `request_id`, `nonce`, `scope_sha256` и массив `observations`. В каждой записи нужны наблюдаемые в одном ответе источника `uid`, `vid`, `field="author.region"`, `raw_region`, `typed_region`, UTC-время `observed_ms` в миллисекундах и SHA-256 исходного доказательства в `evidence_sha256`. Оба значения региона могут быть null только для целевого автора при полученном ответе с точным совпадением UID и VID.
* Исполнитель проверяет весь пакет, время наблюдения и оба контроля. На ожидание Binder-ответа агент отводит 90 секунд. Сервер хранит принятый отчёт в истории задания. Для записи в исследовательский каталог отдельно требуется сверка с оригиналом доказательства.

## Проверка 20 ноября 2026
